# SavePlate 🍽️

SavePlate adalah aplikasi marketplace makanan yang bertujuan untuk mengurangi pemborosan makanan di restoran.  
Konsepnya mirip dengan layanan pesan-antar makanan seperti GoFood, namun dengan perbedaan utama: makanan yang ditawarkan adalah makanan berlebih dari restoran yang masih layak konsumsi tetapi tidak terpakai, dengan harga yang lebih murah.  

## ✨ Fitur Utama
- 🍴 **Marketplace makanan**: restoran dapat menjual makanan sisa yang masih layak konsumsi.  
- 💸 **Harga lebih terjangkau**: makanan dijual dengan harga lebih murah.  
- 🌍 **Kurangi food waste**: membantu mengurangi limbah makanan dari restoran.  
- 📱 **User-friendly**: konsep aplikasi mudah dipahami mirip platform pesan-antar populer.  

## 📂 Struktur Proyek
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: PHP  
- **Database**: MySQL (file `saveplate.sql`)  

## 🚀 Cara Menjalankan
1. Clone repository ini:
   git clone https://github.com/username/SavePlate.git
2. Import database dari file saveplate.sql ke MySQL.
3. Pastikan server web (XAMPP/LAMP/MAMP) aktif.
4. Akses aplikasi melalui browser pada http://localhost/SavePlate.
